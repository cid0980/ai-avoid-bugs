# ai-avoid-bugs

Rules for any AI that builds an app or website, taken from real bugs found by
testing a finished app.

**How to use:** at the start of a project, give the AI
[`AVOID_THESE_BUGS.md`](AVOID_THESE_BUGS.md) and say:

> Follow AVOID_THESE_BUGS.md while you build. Run its Done checklist before you
> tell me anything is finished.

When a new kind of bug is found, add it to the right section and to the
"Real examples" table.
